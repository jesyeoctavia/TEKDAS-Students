# Laporan Proyek Adaptasi

Sumber PDF ada di `generate_report.py`. Jalankan `python generate_report.py` dari folder `proyek_adaptasi` untuk membangun ulang `Laporan_Proyek_Adaptasi.pdf`.

PDF mendokumentasikan status proyek saat ini secara faktual: repository masih berupa scaffold adaptasi dan belum memiliki dataset, konfigurasi data, artefak model, maupun metrik eksperimen. Setelah implementasi lengkap, perbarui isi `generate_report.py` dengan identitas mahasiswa, provenance dataset, hasil eksperimen, dan evaluasi LLM yang benar-benar dihasilkan.
